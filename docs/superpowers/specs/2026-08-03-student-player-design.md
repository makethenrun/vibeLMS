# Студенческий плеер — дизайн

**Дата:** 2026-08-03
**Статус:** в работе (фазами)

Сторона ученика для материалов-конструктора: ученик открывает доступные ему
материалы и проходит их, с проверкой и сохранением результатов.

## Решения (утверждены)
- **С сохранением результатов** (ответы + баллы в БД; ученик возвращается;
  результаты для репетитора — фаза P3).
- **Настоящий drag-and-drop** (@dnd-kit) для drag-форматов — фаза P2.

## Доступ
Ученик видит материалы, доступные его **группам**: `group_members` (student) →
`material_groups` → `materials`. Роуты ученика `/learn/*`, гардом `requireStudent`.

## Декомпозиция
- **P1 (этот срез):** доступ + навигация (материал→разделы→уроки→урок) +
  отображение read-форматов (INFO, AUDIO, VIDEO, IMAGE, CAROUSEL, LINK) + решение
  недраг-форматов с авто-проверкой и баллом: **QUIZ** (выбор/текст, таймер+blur),
  **GAPS** режимы INPUT/SELECT, **FREE** (сохранение, без авто-балла) +
  сохранение результатов (`material_item_submissions`).
- **P2:** @dnd-kit — GAPS DRAG, IMAGE_TASK (все вариации), SENTENCE_TASK,
  MATCH_PAIRS/MATCH. Проверка этих форматов.
- **P3:** экран результатов для репетитора + ручная проверка FREE.

## Модель данных (P1)
`material_item_submissions` — ответ и балл ученика на элемент:
`id, student_id→students, item_id→material_items, answer jsonb, score numeric(5,2)
null, submitted_at`, `unique(student_id, item_id)`. RLS enable / no policies.

Форматы ответов (`answer` jsonb) и проверка — чистые функции `checkItem` в
`lib/materials/scoring.ts` (юнит-тесты). Балл 0..100; `null` = ожидает проверки
(FREE).

## Роуты (P1)
- `/learn` — список доступных материалов.
- `/learn/materials/[materialId]` — разделы→уроки (read-навигация).
- `/learn/lessons/[lessonId]` — прохождение: модули с элементами, каждый
  недраг-элемент интерактивный, кнопка «Проверить» → балл, ответ сохраняется.

Нав: пункт «Обучение» для роли STUDENT → `/learn`. `route-access` разрешает
`/learn` ученику.

## P2 (done 2026-08-03) — drag-and-drop (@dnd-kit)

Все drag-форматы стали интерактивными для ученика, с авто-проверкой и
сохранением. Проверка — в `lib/materials/scoring.ts` (`scoreImageTask`,
`scoreSentenceTask`, MATCH), юнит-тесты.

- **GAPS DRAG** — банк слов → перетаскивание в поля (`AssignBoard`).
- **SENTENCE_TASK**: WORD_ORDER/SENTENCE_ORDER (`SortableChips`), WORD_FROM_LETTERS
  (буквы в позиции, `AssignBoard`), SORT_COLUMNS (`ColumnsBoard`, мульти-контейнер),
  MATCH_PAIRS (`AssignBoard`).
- **MATCH** (старый тип) — через `MatchPairsSolve`.
- **IMAGE_TASK**: TYPE_WORD (ввод), SELECT_WORD (выпадашка из слов+distractors),
  SELECT_IMAGES (клик по картинкам), DRAG_* (перетаскивание слов на картинки,
  `AssignBoard`).

DnD-примитивы: `_components/dnd/{sortable-chips,assign-board,columns-board}.tsx`;
решалки: `_components/solves/*`. @dnd-kit (core/sortable/utilities).

Остаётся **P3** — экран результатов для репетитора + ручная проверка FREE.

## P3 (done 2026-08-03) — результаты для репетитора + ручная проверка FREE

Экран `/materials/[materialId]/results` (гард `requireTutor`, ссылка «Результаты»
на странице материала):
- **Сводка**: таблица ученик → пройдено (N из gradable) → средний балл.
- **На проверке**: свободные ответы (FREE) со `score = null` — текст ответа +
  форма выставления балла (`GradeForm` → `gradeSubmissionAction`).

Ученики — из групп с доступом (`listMaterialStudents`); элементы материала плоско
(`getMaterialItemsFlat`); сабмишены всех учеников
(`getSubmissionsByStudentItem`). После выставления балла ученик видит его вместо
«На проверке».

Плеер (P1–P3) завершён: доступ, прохождение всех форматов (недраг + drag),
авто-проверка, сохранение результатов, ручная проверка FREE, результаты для
репетитора.

## Полировка плеера (2026-08-03)

1. **GAPS DRAG** — инлайновые drop-слоты прямо в тексте (без номеров), банк слов
   снизу (`_components/dnd/fill.tsx`: FillDnd/DropSlot/DragChip/Bank).
2. **IMAGE_TASK drag** — две колонки: картинки (300×300 square rounded) слева,
   слова-рамки справа; перетаскивание слова на картинку.
3. **Фикс. размер** 300×300 rounded для карусели и картинок в упражнениях;
   формат IMAGE (одиночная картинка) — как был.
4. **Просмотр как ученик** для учителя: `/materials/lessons/[id]/preview` +
   кнопка на странице урока. Ответы проверяются локально (`localSubmit` через
   `SubmitContext`), ничего не сохраняется.
5. **Навигация ученика = как у учителя**: два-панельный `Workspace`, справа
   read-only деревья (разделы→уроки, модули→элементы), один модуль на странице
   (`?m=`). Компоненты `student-section-tree` / `student-module-tree`.
6. **Слово из букв** — ряд пунктирных клеток-слотов + плитки букв.

Проверка ответов вынесена через `SubmitContext` (сервер — у ученика,
локальный `checkItem` — в предпросмотре); `useSubmit` принимает content.

## Полировка плеера 2 (2026-08-03)

1. Порядок предложений — вертикальный (`SortableChips vertical`).
2. Учитель смотрит материал с прогрессом ученика: сводка `/results` →
   клик по ученику → `/results/[studentId]` (ответы, баллы, текст FREE) +
   **реакция-эмодзи** на сабмишен (`reaction` в `material_item_submissions`,
   миграция 0015, `setReactionAction`, `ReactionPicker`). Ученик видит реакцию.
3. Формат IMAGE — рисование пометок поверх картинки (`ImageAnnotate`, canvas).
4. Страница материала у ученика — статистика прогресса вместо «Выберите урок».
5. Сопоставление слов — две колонки, рамки 300×300, drag из колонки в колонку.
6. IMAGE_TASK — слова-рамки 300×300 как картинки.
7. DRAG_IMAGE_TO_WORD — теперь тащим именно картинку к слову (реверс).

## Полировка плеера 3 (2026-08-04)

1. **Пиньинь в редакторе** — кнопка «拼音» в rich-text панели: вставка `ü` и
   комбинируемых тоновых знаков (̄ ́ ̌ ̀), которые ставятся на предыдущую гласную.
2. **Просмотр результатов — полноценно по структуре**: `/results/[studentId]`

   текстом FREE и реакциями. Кнопка «Результаты» добавлена и на страницу урока
   (с любого упражнения), не только на страницу материала.
3. **Продолжить с места** — на странице материала у ученика кнопка «Продолжить»
   (Начать/Повторить) ведёт к первому непройденному упражнению
   (`/learn/lessons/[id]?m=…#item-…`). `MaterialItemFlat` дополнен lessonId/moduleId.

Миграции не требуются.
